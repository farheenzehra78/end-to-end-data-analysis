# Data Analysis & Visualization Portfolio

A curated collection of data analysis and visualization projects designed to uncover hidden trends, build predictive models, and drive data-driven decision-making across diverse domains.

![Data Analytics Banner](https://shields.io)

## 📊 Overview

This repository showcases a series of end-to-end data analytics projects. Each project is focused on transforming messy, raw datasets into clean, actionable insights using exploratory data analysis (EDA), statistical modeling, and interactive data visualizations. The goal of this portfolio is to demonstrate the power of data-driven storytelling for both technical and non-technical stakeholders.

---

## 📁 Projects Included

### 1. COVID-19 Trend Analysis
* **Objective:** Analyzed the global spread, recovery tracks, and mortality rates of the pandemic.
* **Methodology:** Time-series forecasting and interactive geospatial mapping.
* **Tools Used:** Python, Pandas, Plotly

### 2. Stock Trading Pattern Analysis
* **Objective:** Explored market trading volumes, historical price movements, and asset volatility.
* **Methodology:** Calculated technical indicators and engineered interactive candlestick patterns.
* **Tools Used:** yFinance, Pandas, Matplotlib, Seaborn

### 3. Housing Market Price Analysis
* **Objective:** Investigated real estate price distributions relative to location, home amenities, and size.
* **Methodology:** Feature engineering and regression modeling for accurate price predictions.
* **Tools Used:** Scikit-learn, Pandas, Tableau

### 4. IoT Sensor Data Analysis
* **Objective:** Monitored live sensor outputs and designed systems for anomaly detection.
* **Methodology:** Pattern recognition and time-series aggregation in connected devices.
* **Tools Used:** Python, SQL, Power BI

---

## 🛠️ Tech Stack

* **Languages & Core:** Python (Pandas, NumPy), SQL
* **Visualization:** Matplotlib, Seaborn, Plotly, Tableau, Power BI

* **Data Visualization & Storytelling:** Creating compelling, intuitive plots that tell a clear business story.
* **Statistical Analysis:** Applying statistical tests and mathematical frameworks to validate insights.
* **Trend Analysis & Forecasting:** Identifying patterns over time to project future outcomes.

## 🚀 How to Run

Follow these steps to set up and run the projects locally.

### 1. Clone the Repository
```bash
git clone https://github.com
cd YOUR-REPO-NAME
```

### 2. Set Up Environment & Dependencies
Ensure you have Python installed, then run the following command to install the required libraries:
```bash
pip install pandas numpy matplotlib seaborn plotly scikit-learn yfinance jupyter
```

### 3. Launch Notebooks
Open the portfolio notebooks locally:
```bash
jupyter notebook
```
